# ember-pages

Static site for **[Ember: Smoke Less](https://apps.apple.com/us/app/ember-smoke-less/id6810363404)** (iOS) - privacy policy and support pages in English and Russian, served by GitHub Pages.

**Live:** https://1ntr0men.github.io/ember-pages/

| Page | English | Russian |
|---|---|---|
| Privacy policy | [privacy-en.html](https://1ntr0men.github.io/ember-pages/privacy-en.html) | [privacy.html](https://1ntr0men.github.io/ember-pages/privacy.html) |
| Support & FAQ | [support-en.html](https://1ntr0men.github.io/ember-pages/support-en.html) | [support.html](https://1ntr0men.github.io/ember-pages/support.html) |

Plain HTML, no dependencies, no build step.

## Notes

- The app links to these URLs (`siteRoot = "https://1ntr0men.github.io/ember-pages"`), and App Store Connect uses the same addresses. Do not rename the repository or the files.
- When the policy text changes, update the effective date in both language versions.
- Source copies of the pages also live in the app repository (`app-store/site/`). Keep both in sync.
